## Getting Started

Follow these steps to get a development environment running locally.

### Prerequisites

Make sure you have Node.js (v16 or above) and a package manager installed. You can use one of:

- npm
- yarn
- pnpm
- bun

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
````

2. Install dependencies:

```bash
npm install
# or
yarn
# or
pnpm install
# or
bun install
```

### Running the Development Server

Start the local development server on [http://localhost:3000](http://localhost:3000):

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open your browser and navigate to `http://localhost:3000` to see the app running.
